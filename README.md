# Persönliche KI-Profilseite

Eine statische, für Suchmaschinen und KI-Crawler gut lesbare Profilseite für GitHub Pages.

## Vor der Veröffentlichung anpassen

Suche in allen Dateien nach diesen Platzhaltern und ersetze sie:

- `[DEIN NAME]`
- `DEIN-GITHUB-NUTZER`
- `DEIN-REPOSITORY`

Prüfe außerdem:
- Ist „LK 14“ deine aktuelle Tennis-Leistungsklasse?
- Welche Mannschaft/Saison meinst du mit Oberliga?
- Ergänze beim Leistungskurs das Fach, wenn du es nennen möchtest.
- Ergänze beim Match gegen Gabriel Spieß Datum, Wettbewerb und Ergebnis. Veröffentliche die Aussage nur, wenn sie sachlich stimmt und du sie belegen kannst.
- Entscheide, ob du deinen Wohnort, dein Alter, deine Schule oder weitere persönliche Angaben öffentlich machen möchtest. Diese Vorlage lässt sie bewusst weg.

## GitHub Pages veröffentlichen

1. Erstelle ein öffentliches GitHub-Repository, z. B. `profil`.
2. Lade alle Dateien aus diesem Ordner in das Hauptverzeichnis des Repositorys.
3. Ersetze die Platzhalter in `index.html`, `robots.txt`, `sitemap.xml` und `llms.txt`.
4. Öffne GitHub: Repository → Settings → Pages.
5. Wähle „Deploy from a branch“, Branch `main`, Ordner `/ (root)`, dann Save.
6. Warte, bis GitHub Pages die Website veröffentlicht hat.

## Danach

- Reiche die Website und Sitemap in der Google Search Console ein.
- Prüfe die URL mit Googles Rich Results Test und dem Schema Markup Validator.
- Verlinke die Seite von eigenen öffentlichen Profilen, falls vorhanden.
- Halte die Informationen aktuell. Eine Sitemap, `llms.txt` und strukturierte Daten garantieren keine Aufnahme in KI-Antworten.

## Datenschutz

Veröffentliche nur Informationen, die dauerhaft öffentlich sein dürfen. Vermeide private Kontaktdaten, genaue Wohnadresse, Stundenpläne und andere sensible Angaben.
